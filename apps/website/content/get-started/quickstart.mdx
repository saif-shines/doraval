Review the skill folder until exit 0. A pocket agent is a later page.

## Core workflow

```bash
# 1. Install ask-dora, review-with-dora, grilling-for-routine, writing-for-routine
npx skills add saif-shines/doraval

# 2. Review the skill folder. No API key.
dora review --quick skills

# 3. Apply safe fixes
dora fix skills --yes

# 4. Read the brief, then edit the skill
dora fix skills --brief

# 5. Review again until exit 0
dora review --quick skills
```

Pass the folder that holds the skills you ship. A check of `.` also scores test fixtures and can exit 1.

Exit `0` clean · `1` issues · `2` could not run.

## Common commands

```bash
dora                         # short --help
dora review --quick skills  # structure only, no API key
dora review --quick --format json
dora scan                    # workspace map
dora fix . --yes             # mechanical only; no TTY
dora memory add "Never use default exports" --weight 8
dora conflicts --dry-run
```

## Review quality

`--quick` is tiers 1–2 (structure + heuristics). No Judge.

```bash
dora review --quick .
dora review --quick ./path/to/skill-dir
dora review --quick --ci skills # CI gate, no API key
dora review --deep                 # require Judge
dora review --run .                # live-run scenarios.yaml; not --quick
```

`--run` feeds each `when` to the agent twice: no skill, then with the skill. It needs an agent and an API judge. Exit `2` if either is missing. Tiers: [Review tiers](/concepts/review-tiers/).

## Pocket agent

A pocket agent is one unattended loop. Type this in the agent:

```text
/ask-dora turn this loop-able check into a routine
```

That loads `grilling-for-routine`. After one good one-pass, apply the folder. Model: [Pocket agent](/concepts/pocket-agent/). Walkthrough: [Run a pocket agent](/get-started/pocket-agents/). Apply: [Apply and watch](/get-started/apply-and-watch/). CLI: [dora harness](/commands/harness/).

## Fix

```bash
dora fix . --dry-run
dora fix . --yes                 # agents / CI
dora fix . --brief               # Judgment items; then replace
```

Mechanical issues apply with `--yes`. Judgment items do not. Re-run `dora review --quick` until exit `0`.

## Memory

```bash
dora memory add "Never use default exports" --weight 8
dora memory list
dora memory promote              # hard rules → AGENTS.md
```

Weights: **8+** hard · **5** default · **1–3** soft. [Memory](/concepts/memory/).

## Common mistakes

- Empty `dora` prints `--help`. It does not Scan. Use `dora scan` for a workspace map.
- `dora new` and `dora reconcile` exit `2`. Use `dora skill new` and `dora conflicts --dry-run`.
