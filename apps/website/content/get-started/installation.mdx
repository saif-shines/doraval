Install the `dora` CLI so you can scan and review agent context on this machine. Then add the doraval skill so Claude, Cursor, Codex, Copilot, or Grok can run the same checks.

After a permanent install, `dora` and `doraval` are the same binary.

## Homebrew (recommended, macOS)

```bash
brew tap saif-shines/tap && brew trust saif-shines/tap && brew install doraval
```

Upgrade later with `brew upgrade doraval` or `dora update`.

## npm (cross-platform)

```bash
npm install -g @hacksmith/doraval
```

Ships a prebuilt binary per platform (macOS arm64/x64, Linux x64/arm64, Windows x64). Node ≥ 14.18.

## Bun

```bash
bun add -g @hacksmith/doraval
# one-shot:
bunx @hacksmith/doraval
```

## One-shot (no install)

```bash
npx @hacksmith/doraval
```

Use this when you do not want `dora` on `PATH`. The skill falls back to the same command when `dora` is missing.

## Alpine / musl

Platform binaries target glibc. On Alpine/musl, run from source with Bun:

```bash
bunx @hacksmith/doraval
```

## AI agent setup

Install the skill so Claude Code, Cursor, Codex, Copilot, or Grok can load the Doraval checklist.

### Coding assistants

```bash
npx skills add saif-shines/doraval
```

This fetches the skill from the repository. List or remove it with `npx skills list` and `npx skills remove`.

### AGENTS.md / CLAUDE.md

Add this block to `AGENTS.md` (or `CLAUDE.md`) if you want the same workflow without the skill:

```markdown
## Context review

Use `dora` to review agent context. Run `dora --help` for all commands.

Core workflow:
1. `dora review --quick` - structure and heuristics, no Judge
2. `dora fix <path> --yes` - apply mechanical fixes
3. Re-run `dora review --quick` until exit `0`
```

If `dora` is not on `PATH`, use `npx @hacksmith/doraval` in place of `dora`.

## Verify

```bash
# CLI (after permanent install)
doraval --version
dora --version

# skill (skills CLI)
npx skills list
```

## Common mistakes

- Global install succeeds but `dora` is missing: ensure your npm/Bun global bin directory is on `PATH`.
- Alpine or musl hosts: use Bun (`bunx` / `bun add -g`), not the glibc platform binary.
- `npx skills add` fails: need network and a recent Node; retry the same command.
- Skipped skill add: coding assistants will not auto-load the Doraval checklist until `npx skills add saif-shines/doraval`.
