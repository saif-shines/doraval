`dora` reviews skills, rules, and memory so Claude, Cursor, Codex, Copilot, and Grok run from context you can trust. The first command is `dora review --quick`. Empty `dora` prints `--help`.

```bash
npx skills add saif-shines/doraval
dora review --quick
```

`--quick` is structure and heuristics. No Judge. No API key.
