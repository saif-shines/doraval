`dora` does two jobs. It reviews skills, rules, and memory so Claude, Cursor, Codex, Copilot, and Grok run from context you can trust. It also saves a **pocket agent**: one unattended loop, one machine, one user.

The first command is `dora review --quick`. Empty `dora` prints `--help`.

```bash
npx skills add saif-shines/doraval
dora review --quick
```

`--quick` is structure and heuristics. No Judge. No API key.

A pocket agent starts as `/ask-dora` plus a loop-able idea. The saved folder is a routine. Model: [Pocket agent](/concepts/pocket-agent/). Walkthrough: [Run a pocket agent](/get-started/pocket-agents/).
