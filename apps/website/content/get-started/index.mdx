`dora` reviews skills, rules, and memory so Claude, Cursor, Codex, Copilot, and Grok run from context you can trust.

The first command is `dora review --quick`. Empty `dora` prints `--help`.

```bash
npx skills add saif-shines/doraval
dora review --quick skills
```

Pass the folder that holds the skills you ship. A check of `.` also scores test fixtures and can exit 1.

`--quick` checks structure. No API key.
