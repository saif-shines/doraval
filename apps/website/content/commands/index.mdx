`dora` and `doraval` are the same binary. Use `npx @hacksmith/doraval` if `dora` is not on `PATH`.

```bash
dora --help                  # first loop + command list
dora review --help           # this command
dora agent-help              # live map (add --json to parse)
```

Exit `0` clean · `1` issues · `2` could not run.

## Scan

```bash
dora                         # workspace health (alias: dora scan)
dora --json                  # same as --format json
dora --ci                    # implies JSON
dora --cwd "$GITHUB_WORKSPACE"
```

Read-only. No LLM. No API key.

## Review

```bash
dora review --quick .        # structure + heuristics; Findings first
dora review --quick ./path/to/skill-dir
dora review --all --quick --ci
dora review --deep .         # require Judge; exit 2 if none
dora review --sessions .     # require session evidence
dora review CLAUDE.md
```

`--quick` is the first Review. JSON comes after:

```bash
dora review --quick --json
```

Tiers: [Review tiers](/concepts/review-tiers/).

## Fix

```bash
dora fix . --dry-run
dora fix . --yes             # mechanical; no TTY
dora fix . --brief           # judgment items, then edit
```

Re-run `dora review --quick` until exit `0`.

## New

```bash
dora new skill --for claude --name review-pr --description "Reviews PRs" --yes
dora new rule --for cursor --name no-default-exports --yes
dora new plugin --for claude --name my-plugin --yes
```

Always pass `--for`. Then `dora review --quick` the new path.

## Skill

```bash
dora skill unused
dora skill remove ghost --dry-run
dora skill remove ghost --yes
dora skill remove ghost --for claude --yes
dora skill restore ghost --yes
```

`dora skill unused` lists Remove candidates. It writes nothing.

Deletes an Authored Skill. Quarantines a Global Skill (home copy). Restore puts that copy back.

A detected agent needs `--yes` or `--dry-run`. A name clash needs `--for`, `--global`, or a path.

Scan and Review mark an Authored Skill that was never invoked in the Review window, and is not a Recent install, as [R034](/reference/rules/R034). That is a Remove candidate. A Global Skill is never a Remove candidate from one project’s Sessions.

## Memory

```bash
dora memory add "Never use default exports" --weight 8
dora memory add "Prefer named exports" --global
dora memory list
dora memory promote          # hard rules → AGENTS.md
dora memory promote --dry-run
dora memory context --json --quiet
dora memory stash path/to/notes.md
dora memory restore path/to/notes.md
dora memory sync
```

Weights: **8+** hard · **5** default · **1–3** soft. [Memory](/concepts/memory/).

## Reconcile

```bash
dora reconcile --dry-run
dora reconcile --apply --yes
```

Settles Claude-vs-Cursor contradictions into `AGENTS.md`.

## Sessions

```bash
dora sessions
dora sessions --agent claude --limit 20
dora sessions show <sessionId>
```

Read-only. Adapters: Claude, Grok, Cursor, Codex, Copilot.

## Config

```bash
dora config                  # TTY hub
dora config setup            # Judge wizard
dora config get eval.model
dora config set eval.model gpt-4.1
dora config set eval.judge auto
```

`--deep` needs a Judge. Do not paste API keys into chat.

## Bump

```bash
dora bump patch
dora bump minor ./plugins
dora bump 1.2.3 --yes
```

## Providers

```bash
dora providers               # packaging matrix, not “who is installed”
dora providers --json
```

Who is installed is `dora` (scan).

## Update

```bash
dora update
dora update --check
dora update --via npm
```

## Agent-help

```bash
dora agent-help              # every verb, read-only vs writes
dora agent-help --json       # same tree
dora agent-help review       # one verb
```

Replaces `--capabilities`.

## Completions

```bash
dora --completion bash
dora --completion zsh
dora --completion fish
```
