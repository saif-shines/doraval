| **What** | An Authored Skill was never invoked in the Review window and is not a Recent install. That is a Remove candidate. |
| **Why** | Dead Authored Skills still load into agent context. Recommend remove. A Global Skill or a Recent install is never this Finding — see [R029](/reference/rules/R029). |

## How to fix

1. Confirm the Skill is Authored and older than Install age (default 90 days).
2. Delete the Skill directory. Git can bring an Authored Skill back.
3. List first: `dora skill unused`. Unused-but-recent is named **never invoked**. It is not a Remove candidate. Then `dora skill remove <name> --dry-run` for a Remove candidate. Home Skills: `dora skill unused --global`. A Global Skill that this repo never invoked stays on [R029](/reference/rules/R029). It is not a project Remove candidate.
