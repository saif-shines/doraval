# Event list is the Session IR

A Session is a list of Events plus a derived summary. Review, unused, and `dora sessions` read that load. We rejected widening `SessionPrimitives` (cannot unlock Later analyse) and a required span tree (Grok, Cursor, and Copilot have no parents). A Content table is a later view, not a grain. We do not invent fields the log does not have (ADR companion to Capture-wide / Fill when present in `CONTEXT.md`).
